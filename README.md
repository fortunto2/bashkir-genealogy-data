# Открытые данные по генеалогии Южного Урала

Указатель наборов данных: оцифрованные архивные источники по башкирским
деревням Орского и Оренбургского уездов Оренбургской губернии — нынешним
Зианчуринскому и Мелеузовскому районам Башкортостана и востоку Оренбургской
области.

Каждый набор — это **имя человека, привязанное к месту и к архивному шифру**,
по которому заказывается сам документ. Всё под CC BY 4.0, с постоянными DOI.

## Наборы

### Домохозяева Усерганского кантона по подворной переписи 1920 года

**2618 записей · 53 населённых пункта · 7 волостей**

Фамилия, имя и отчество хозяина двора, селение, волость и шифр дела
Национального архива Республики Башкортостан. Последний массовый документ, где
башкирская деревня расписана по дворам поимённо; для многих семей —
единственное упоминание предка между ревизией 1859 года и Великой Отечественной
войной.

→ [github.com/fortunto2/usergan-1920](https://github.com/fortunto2/usergan-1920)
· DOI [10.5281/zenodo.22747578](https://doi.org/10.5281/zenodo.22747578)

### Ревизские сказки 1816 и 1859 годов: Бикбердина и Барангулова

**2 371 человек · 295 записей дворов · дела 145, 146, 161, 170, 704, 706**

Жители двух деревень Оренбургского уезда по VII и X ревизиям: имя, слова
родства, возраст на прошлую и эту ревизию, год смерти, двор и кадр скана в деле
НА РБ, ф. И-138, оп. 2. Женская половина листа прочитана там, где она есть в
сканах. Расшифровка сделана ИИ-моделью без сплошной сверки человеком, поэтому в
каждой строке есть исходная запись целиком.

→ [bikberdina-barangulova-1816-1859/](bikberdina-barangulova-1816-1859/) в этом репозитории
· DOI репозитория [10.5281/zenodo.22748057](https://doi.org/10.5281/zenodo.22748057) (набор входит с версии 1.1)

### Уроженцы Орского уезда в документах Первой мировой войны, 1914–1918

**Версия 2.0: 20 473 записи по уезду целиком** (деревня у 10 779, ссылка на скан у 8 344);
в версии 1.2 — 1368 записей по двум волостям

Раненые, больные, убитые и пропавшие без вести с привязкой к деревне рождения и
шифром РГВИА. По Первой мировой генеалогическая работа почти не ведётся, а
именно в этих карточках сохранились деревенские привязки, которых нет в других
источниках той эпохи.

→ [github.com/fortunto2/orsk-uezd-ww1](https://github.com/fortunto2/orsk-uezd-ww1)
· DOI [10.5281/zenodo.23503840](https://doi.org/10.5281/zenodo.23503840) (2.1, волости нормализованы)

## Чем это отличается от поиска по базам

Порталы вроде «Памяти народа» или «Открытого списка» ищут по фамилии в масштабе
страны и тонут в однофамильцах. Здесь наоборот: **сначала место, потом имя**.
Если известна деревня, набор даёт всех её жителей на определённый год и шифр
дела, по которому смотрят оригинал.

Второе отличие — **честные границы**. В каждом наборе описано, чего в нём нет и
почему: где данные не удалось сопоставить надёжно, там поле оставлено пустым, а
не заполнено догадкой.

## Как пользоваться

1. Найдите деревню предков в наборе по переписи 1920 года — это даст фамилии,
   которые в ней жили.
2. Проверьте те же фамилии в наборе по Первой мировой: там указан год и часть.
3. Для XIX века идите в ревизские сказки: там отец, братья и сыновья в одной
   записи двора.
4. По архивному шифру закажите дело в НА РБ или РГВИА и смотрите оригинал.

⚠️ Наборы — **указатели, а не источники**. Каждую находку следует сверять с
самим делом: распознавание печатных таблиц даёт ошибки, а написание имён в
документах плавает — искать стоит по нескольким вариантам.

## Инструменты (`tools/`)

Небольшие скрипты, которыми собраны наборы данных из
наборы выше.
Каждый — один файл, без регистрации на сайтах-источниках. Python 3.11+.

| Скрипт | Источник | Что делает |
|---|---|---|
| `tools/obd.py` | ОБД «Мемориал» (obd-memorial.ru) | поиск по фамилии/имени/отчеству/году, карточка, выгрузка сканов |
| `tools/gwar-sweep.py` | «Память героев Великой войны 1914–1918» (gwar.mil.ru) | сплошная выгрузка по полю: `birth_place_uezd Орский orsk` |
| `tools/dresden.py` | база советских военнопленных, Дрезден (stsg.de) | поиск по фамилии; **только немецкая транслитерация** (`Iwanow`, не `Иванов`) |
| `tools/fs-places-export.py` | справочник мест FamilySearch | населённые пункты уезда с координатами и старыми названиями |
| `tools/wiki-check.py` | Википедия | жив ли ваш текст в статьях: опорные фразы, откаты, кто правил после вас |

```bash
uv run --with requests tools/obd.py f=Иванов n=Иван s=Иванович
python3 tools/gwar-sweep.py birth_place_uezd "Орский уезд" orsk
uv run --with requests tools/dresden.py Iwanow
OUT=./out python3 tools/fs-places-export.py
cp tools/wiki-watch.example.json family/wiki-watch.json && uv run tools/wiki-check.py --user
```

### Нормализация названий

Писари записывали волости и деревни на слух: у одной волости бывает десятки
написаний. Нормализатор (Левенштейн + словарь синонимов + классификатор для
хвоста) лежит рядом с данными, на которых он проверен:
[orsk-uezd-ww1/scripts/normalize-volost.py](https://github.com/fortunto2/orsk-uezd-ww1/blob/main/scripts/normalize-volost.py).

### Ловушки, на которых обжигались

- **Сначала место, потом имя.** Поиск по фамилии тонет в однофамильцах; фильтр
  по губернии и уезду надёжнее, чем по волости (её перевирали сильнее деревни).
- **Пустой ответ ≠ «нет данных».** Проверяйте инструмент на заведомо известном
  запросе: у одного портала поле фильтра молча игнорировалось и возвращало всё.
- Часть российских архивных сайтов из-за рубежа не открывается — нужен
  российский IP. Скрипты сами туннель не поднимают.
- Не нагружайте государственные сайты: в скриптах стоят паузы между запросами.
